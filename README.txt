Quick start:
1. Extract the ZIP file.
2. Open index.html in a browser (double-click it).
3. To publish online, upload index.html to a static hosting service such as GitHub Pages or Netlify.

Contact form:
The form uses a mailto link. It opens the visitor's email app with the message prefilled; it does not submit to a server. For server-side submissions, connect a form backend (for example, Formspree) and update the form code.
